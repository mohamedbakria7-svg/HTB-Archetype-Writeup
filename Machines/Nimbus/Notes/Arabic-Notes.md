# Nimbus - Arabic Technical Notes

## 1. Cloud Security

**Cloud Security — أمن الحوسبة السحابية**

حماية الخدمات والبنية التحتية السحابية من الوصول غير المصرح به وتسريب البيانات.

## 2. AWS

**Amazon Web Services**

منصة خدمات سحابية توفر خدمات مثل التخزين والحوسبة وإدارة الصلاحيات.

مصطلحات مهمة:
- IAM: إدارة المستخدمين والأدوار والصلاحيات.
- S3: خدمة تخزين الملفات والكائنات.
- EC2: خدمة تشغيل الخوادم الافتراضية.
- SQS: خدمة طوابير الرسائل.

## 3. SSRF

**Server-Side Request Forgery**

ثغرة تسمح للمهاجم بالتأثير على الطلبات التي يرسلها الخادم إلى موارد أخرى.

الخطر المحتمل:
- الوصول إلى خدمات داخلية.
- كشف معلومات البنية التحتية.
- الوصول إلى بيانات Metadata عند ضعف الحماية.

## 4. Job Scheduler

نظام مسؤول عن جدولة المهام وتنفيذها تلقائياً.

يجب فحص:
- كيفية إرسال المهام.
- طريقة التحقق من المدخلات.
- صلاحيات عملية التنفيذ.
- كيفية التعامل مع الملفات والرسائل.

## 5. Container Security

**أمن الحاويات**

حماية البيئات المعزولة التي تشغل التطبيقات والخدمات.

نقاط الفحص:
- صلاحيات المستخدم داخل الحاوية.
- الملفات الحساسة.
- متغيرات البيئة.
- الاتصالات بالخدمات الأخرى.

## 6. Lessons Learned

- لا تفترض أن الخدمات السحابية محمية تلقائياً.
- افحص صلاحيات IAM بعناية.
- تحقق من حماية خدمات Metadata.
- افحص آلية تنفيذ المهام والرسائل.
- وثّق كل نتيجة بدليل قابل للتحقق.

## Important Note

هذه ملاحظات تعليمية للمفاهيم المرتبطة بالجهاز، وليست سجلاً كاملاً لكل الأوامر أو نتائج الاستغلال.

# 01 - Reconnaissance

## Objective
Identify the target machine's exposed services and initial attack surface.

## Methodology
The reconnaissance phase focuses on discovering open ports, running services, and service versions.

## Findings
- Target: DevHub
- Open ports: 22, 80, 6274
- Services: SSH, HTTP, and the web application service.

# DevHub - Arabic Technical Notes

## 1. Reconnaissance

**Reconnaissance — الاستطلاع**

المرحلة الأولى لجمع المعلومات عن الجهاز والخدمات المكشوفة.

- Nmap: أداة لفحص المنافذ والخدمات.
- Open Port: منفذ مفتوح يستقبل الاتصالات.
- Service Enumeration: تحديد الخدمات وإصداراتها.

## 2. Enumeration

**Enumeration — جمع المعلومات التفصيلية**

الانتقال من اكتشاف الخدمات إلى فهم وظائفها وطريقة عملها.

- MCP: Model Context Protocol.
- MCPJam Inspector: واجهة لفحص خدمات MCP.
- JupyterLab: بيئة تفاعلية للعمل باستخدام دفاتر Jupyter.
- Token: قيمة تستخدم للمصادقة والوصول إلى خدمة.

## 3. Vulnerability Analysis

**Vulnerability Analysis — تحليل الثغرات**

تحديد نقاط الضعف وفهم تأثيرها الأمني.

- RCE: Remote Code Execution، تنفيذ أوامر عن بُعد.
- Attack Surface: سطح الهجوم، أي نقاط التفاعل التي يمكن استهدافها.
- CVE: رقم مرجعي لتعريف ثغرة أمنية منشورة.

## 4. Initial Access

**Initial Access — الوصول الأولي**

الحصول على أول وصول إلى النظام.

الحسابات التي ظهرت خلال مسار الحل:
- `mcp-dev`
- `analyst`

JupyterLab Token كان جزءاً من مسار الوصول إلى JupyterLab.

## 5. Privilege Escalation

**Privilege Escalation — تصعيد الصلاحيات**

الانتقال من حساب محدود الصلاحيات إلى حساب أعلى امتيازاً.

مصطلحات مهمة:
- API Key: مفتاح يستخدم للوصول إلى واجهة برمجية.
- SSH: بروتوكول اتصال وإدارة عن بُعد.
- Private Key: مفتاح خاص يستخدم في المصادقة.
- Root: حساب المدير الأعلى في أنظمة Linux.

في مسار DevHub:
- تم العثور على OPSMCP API Key.
- ظهرت الدالة `ops._admin_dump`.
- تم استخراج مفتاح SSH الخاص بـ root.
- تحقق الوصول إلى root.

## 6. Lessons Learned

1. لا تفترض أن الخدمة المكشوفة آمنة لمجرد أنها تعمل بصورة طبيعية.
2. افحص آليات المصادقة في خدمات MCP.
3. احمِ Tokens وAPI Keys من التسريب.
4. قيّد الوظائف الإدارية الحساسة.
5. احمِ مفاتيح SSH الخاصة.

## Important Reminder

هذه الملاحظات تلخص مسار الحل المسجل في المحادثات. يجب الرجوع إلى الأدلة الفعلية قبل إضافة تفاصيل أو أوامر أو نتائج غير موثقة.
